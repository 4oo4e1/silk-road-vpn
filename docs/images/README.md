# Screenshots

Drop your own screenshots in **this folder** (`docs/images/`) using the exact
file names below. They are referenced from both `README.md` and `README_FA.md`,
so once you add them they will render automatically.

| File name          | What to capture                                   |
| ------------------ | ------------------------------------------------- |
| `home.png`         | The Mini App home screen (main menu).             |
| `purchase.png`     | The buy / plan selection & checkout screen.       |
| `wallet.png`       | The wallet screen (balance + transactions).       |
| `services.png`     | The "my services" screen with an active service.  |
| `support.png`      | The support / ticket screen.                      |
| `admin-panel.png`  | The admin panel dashboard.                        |

## Tips for good screenshots

- Open the Mini App inside Telegram and use your device's screenshot feature
  (or Telegram Desktop / Telegram Web for crisp captures).
- **Blur or crop out any real customer data** (Telegram IDs, names,
  card numbers, subscription links) before committing.
- PNG is preferred; keep each image reasonably small (< 500 KB).
