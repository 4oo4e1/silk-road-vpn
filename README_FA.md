## 📖 معرفی پروژه

**جاده ابریشم** یک پلتفرم آماده و سرورلس برای فروش اشتراک VPN به‌صورت مستقیم در
داخل تلگرام است. مشتری پلن‌ها را می‌بیند، پرداخت می‌کند (با کیف پول داخلی یا
کارت‌به‌کارت) و لینک اشتراک خود را **به‌صورت کاملاً خودکار** دریافت می‌کند — همه
بدون خروج از تلگرام.

تمام پروژه روی **پلن رایگان Cloudflare** اجرا می‌شود:

- یک **ربات تلگرام** که `/start`، رسیدهای پرداخت و تأییدهای ادمین را مدیریت می‌کند.
- یک **مینی‌اپ تلگرام** (فروشگاه + پنل ادمین) که به‌صورت فایل استاتیک از همان
  Worker سرو می‌شود.
- یک **Cloudflare Worker** به‌عنوان بک‌اند (وب‌هوک + REST API).
- پایگاه‌داده **Cloudflare D1** (SQLite).
- **Cloudflare KV** برای کش و نگه‌داری وضعیت‌های کوتاه‌مدت.

این پروژه **بدون مرحله‌ی build** و **بدون فریم‌ورک** است — فقط جاوااسکریپت خام
(ES modules) و یک Worker. تمام پیکربندی در سکرت‌های Cloudflare، فایل
`wrangler.toml` و جدول `settings` قرار دارد، بنابراین می‌توانید این مخزن را
منتشر و **بدون تغییر حتی یک خط از کد** دیپلوی کنید.

> ⚠️ این یک نرم‌افزار فروشگاهی است. رعایت قوانین و شرایط استفاده‌ی تلگرام و
> Cloudflare بر عهده‌ی خود شماست.

## ✨ امکانات

### سمت مشتری
- 🛍️ **فروشگاه** — مشاهده پلن‌های فعال همراه با قیمت و مدت.
- 💳 **کیف پول داخلی** — شارژ با کارت‌به‌کارت و پرداخت فوری.
- ⚡ **تحویل خودکار** — خرید با کیف پول، لینک اشتراک را در چند ثانیه تحویل می‌دهد.
- 🧾 **کارت‌به‌کارت** — پرداخت با واریز، ارسال عکس رسید و فعال‌سازی خودکار پس از تأیید.
- 📦 **سرویس‌های من** — مشاهده اشتراک‌های فعال، روزهای باقی‌مانده و تمدید.
- ♻️ **تمدید** — تمدید سرویس موجود با کیف پول یا کارت.
- 🎫 **پشتیبانی** — گفتگو با ادمین از داخل اپ.

### سمت ادمین
- 📊 **داشبورد** — فروش (روز / هفته / ماه / سال)، کاربران، موجودی، موارد در انتظار.
- 🧾 **تأیید رسید** — تأیید/رد پرداخت‌ها از پنل **یا** مستقیماً از داخل ربات.
- 👥 **مدیریت کاربران** — جستجو، مشاهده پروفایل، تغییر کیف پول، مسدودسازی، ارسال پیام.
- 📦 **مدیریت پلن‌ها** — ساخت/ویرایش/حذف کامل پلن‌های اشتراک.
- 🗂️ **انبار VPN** — افزودن تکی یا گروهی اکانت‌ها؛ واگذاری خودکار هنگام فروش.
- 🔧 **ابزار سرویس** — تمدید یا غیرفعال‌سازی هر اشتراک.
- 📣 **پیام همگانی** — ارسال پیام به همه‌ی کاربران به‌صورت دسته‌ای و امن.
- ⚙️ **تنظیمات** — ویرایش اطلاعات کارت و آیدی کانال در لحظه.

### مهندسی
- 🔐 **اعتبارسنجی HMAC روی `initData` تلگرام** در هر درخواست API — درخواست‌ها جعل‌ناپذیرند.
- 🛡️ **اعتبارسنجی سکرت وب‌هوک** روی نقطه‌ی پایانی ربات.
- 🏁 **ایمن در برابر شرایط رقابتی (race-safe)** در کسر کیف پول و واگذاری اکانت VPN.
- ⏰ **زمان‌بند (Cron)** که اشتراک‌های منقضی را به‌صورت خودکار منقضی می‌کند.
- 🌐 **رابط کاربری راست‌چین فارسی** با تم روشن/تیره هماهنگ با تلگرام.

## 🚀 راهنمای نصب

### پیش‌نیازها

- یک [حساب Cloudflare](https://dash.cloudflare.com/sign-up) (پلن رایگان کافی است).
- [Node.js](https://nodejs.org/) نسخه ۱۸ به بالا و npm.
- ابزار Wrangler: `npm install -g wrangler`
- یک حساب تلگرام و یک ربات ساخته‌شده با [@BotFather](https://t.me/BotFather).

### ۱. کلون و پیکربندی

```bash
git clone https://github.com/4oo4e1/silk-road-vpn.git
cd silk-road-vpn

# ساخت کانفیگ واقعی از روی نمونه (این فایل در گیت نادیده گرفته می‌شود)
cp wrangler.toml.example wrangler.toml

# ورود به Cloudflare
wrangler login
```

### ۲. ساخت منابع Cloudflare

```bash
# پایگاه‌داده D1 — مقدار database_id چاپ‌شده را در wrangler.toml قرار دهید
wrangler d1 create silk-road-db

# فضای KV — مقدار id چاپ‌شده را در wrangler.toml قرار دهید
wrangler kv namespace create KV
wrangler kv namespace create KV --preview   # به‌عنوان preview_id قرار دهید
```

شناسه‌های بازگشتی را در `wrangler.toml` قرار دهید (`database_id`، `id` و
`preview_id` مربوط به KV).

### ۳. اعمال اسکیمای پایگاه‌داده

```bash
wrangler d1 execute silk-road-db --remote --file=schema.sql
```

### ۴. تنظیم سکرت‌ها

```bash
wrangler secret put TELEGRAM_TOKEN            # از @BotFather
wrangler secret put TELEGRAM_WEBHOOK_SECRET   # یک رشته‌ی تصادفی دلخواه
```

### ۵. دیپلوی

```bash
wrangler deploy
```

Wrangler آدرس Worker شما را چاپ می‌کند (مثل
`https://silk-road-vpn.YOUR_SUBDOMAIN.workers.dev`). آن را در `wrangler.toml` در
مقدار `MINIAPP_URL` قرار دهید و یک‌بار دیگر `wrangler deploy` بزنید تا دکمه‌ی
ربات آدرس درست را باز کند.

### ۶. ثبت وب‌هوک تلگرام

مقادیر را جایگزین و این دستور را اجرا کنید (در ترمینال یا مرورگر):

```bash
curl "https://api.telegram.org/bot<TELEGRAM_TOKEN>/setWebhook?url=https://<YOUR_WORKER_URL>/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

### ۷. تبدیل خودتان به ادمین

شناسه‌ی عددی تلگرام خود را از [@userinfobot](https://t.me/userinfobot) بگیرید و در
جدول `settings` قرار دهید:

```bash
wrangler d1 execute silk-road-db --remote \
  --command "UPDATE settings SET value='[\"YOUR_ADMIN_TELEGRAM_ID\"]' WHERE key='admin_ids';"
```

ربات خود را باز کنید، **Start** را بزنید و روی دکمه‌ی فروشگاه ضربه بزنید — حالا
باید دکمه‌ی **پنل ادمین** را هم ببینید. 🎉

## ⚙️ راهنمای پیکربندی

این پروژه عمداً از فایل `.env` استفاده **نمی‌کند** (چون Cloudflare Workers آن را
نمی‌خواند). پیکربندی در سه محل قرار دارد:

1. **سکرت‌ها** — با `wrangler secret put` (رمزنگاری‌شده، هرگز در مخزن نیست).
2. **`wrangler.toml`** — متغیرهای ساده + شناسه‌ی منابع (در گیت نادیده گرفته می‌شود؛
   از `wrangler.toml.example` به‌عنوان الگو استفاده کنید).
3. **جدول `settings`** — قابل ویرایش در لحظه از پنل ادمین.

### جدول کامل پیکربندی

| کلید | نوع | محل قرارگیری | توضیح |
| --- | --- | ----------- | ----- |
| `TELEGRAM_TOKEN` | سکرت | `wrangler secret put` | توکن ربات از @BotFather. برای فراخوانی Bot API و اعتبارسنجی `initData` مینی‌اپ. |
| `TELEGRAM_WEBHOOK_SECRET` | سکرت | `wrangler secret put` | یک رشته‌ی تصادفی دلخواه. هنگام `setWebhook` به تلگرام داده می‌شود و در هر فراخوانی وب‌هوک بررسی می‌شود. |
| `MINIAPP_URL` | متغیر | `wrangler.toml` → `[vars]` | آدرس عمومی HTTPS مربوط به Worker/مینی‌اپ. آدرسی که دکمه‌ی ربات باز می‌کند. |
| `ASSETS` | بایندینگ | `wrangler.toml` → `[assets]` | سرو کردن مینی‌اپ `src/frontend` به‌صورت فایل استاتیک (SPA). |
| `DB` | بایندینگ | `wrangler.toml` → `[[d1_databases]]` | پایگاه‌داده D1. نیازمند `database_name` + `database_id`. |
| `KV` | بایندینگ | `wrangler.toml` → `[[kv_namespaces]]` | فضای KV برای کش + وضعیت. نیازمند `id` + `preview_id`. |
| `crons` | تریگر | `wrangler.toml` → `[triggers]` | زمان‌بندی کار انقضای اشتراک (پیش‌فرض: ساعتی). |
| `card_number` | تنظیمات | جدول `settings` | شماره کارت نمایش‌داده‌شده به مشتری برای پرداخت کارت‌به‌کارت. قابل ویرایش در پنل ادمین. |
| `card_owner` | تنظیمات | جدول `settings` | نام صاحب کارت که کنار شماره کارت نمایش داده می‌شود. قابل ویرایش در پنل ادمین. |
| `channel_id` | تنظیمات | جدول `settings` | آیدی کانال عمومی تلگرام شما (مثل `@YourChannel`). |
| `admin_ids` | تنظیمات | جدول `settings` | آرایه‌ی JSON از شناسه‌های عددی تلگرام مجاز برای ورود به پنل ادمین. |

> ✅ **نیازی به ویرایش سورس نیست.** همه‌ی موارد بالا از طریق سکرت‌ها،
> `wrangler.toml` یا جدول `settings` پیکربندی می‌شوند.

## ☁️ راه‌اندازی Cloudflare Worker

کل Worker توسط `wrangler.toml` تعریف می‌شود (که از `wrangler.toml.example` کپی
شده). بلوک‌های کلیدی:

- **`[assets]`** مینی‌اپ `src/frontend` را به‌صورت SPA سرو می‌کند، در حالی که
  `run_worker_first` مسیرهای `/webhook`، `/api/*` و `/health` را در اختیار کد
  Worker نگه می‌دارد.
- **`[[d1_databases]]`** پایگاه‌داده D1 را به‌صورت `env.DB` بایند می‌کند.
- **`[[kv_namespaces]]`** فضای KV را به‌صورت `env.KV` بایند می‌کند.
- **`[triggers].crons`** تابع `runScheduledJobs()` را برای انقضای اشتراک‌ها اجرا می‌کند.

دستورهای پرکاربرد:

```bash
wrangler dev          # اجرای محلی
wrangler deploy       # دیپلوی روی Cloudflare
wrangler tail         # لاگ زنده از Worker دیپلوی‌شده
```

## 🤖 راه‌اندازی ربات تلگرام

1. با [@BotFather](https://t.me/BotFather) گفتگو کنید → `/newbot` → نام و یوزرنیم انتخاب کنید.
2. **توکن ربات** را کپی و به‌عنوان سکرت `TELEGRAM_TOKEN` تنظیم کنید.
3. **دکمه‌ی منوی مینی‌اپ** را تنظیم کنید تا ربات فروشگاه شما را باز کند:
   - `/mybots` → انتخاب ربات → **Bot Settings** → **Menu Button** →
     **Configure Menu Button** → ارسال `MINIAPP_URL`.
   - (اختیاری) `/setdescription`، `/setabouttext` و `/setuserpic` برای برندینگ ربات.
4. وب‌هوک را ثبت کنید (مرحله‌ی ۶ نصب).

برای بررسی تنظیم‌بودن وب‌هوک:

```bash
curl "https://api.telegram.org/bot<TELEGRAM_TOKEN>/getWebhookInfo"
```

## 🗄️ راه‌اندازی پایگاه‌داده

اسکیما در [`schema.sql`](schema.sql) قرار دارد. با این دستور اعمالش کنید:

```bash
wrangler d1 execute YOUR_DB_NAME --remote --file=schema.sql
```

این دستور جدول‌ها (`users`، `plans`، `vpn_accounts`، `orders`،
`subscriptions`، `wallet_transactions`، `payment_receipts`، `tickets`،
`ticket_messages`، `settings`)، ایندکس‌ها، یک پلن نمونه و ردیف‌های تنظیماتِ
**placeholder** را می‌سازد. مقادیر placeholder را با مقادیر خودتان جایگزین کنید
(از پنل ادمین یا با SQL) — به راهنمای پیکربندی مراجعه کنید.

افزودن موجودی VPN: از تب **VPN** در پنل ادمین استفاده کنید (افزودن تکی یا گروهی).
قالب گروهی، ۴ خط برای هر اکانت است: `email`، `password`، `subscription_url`،
`dashboard_url`.

## 🎨 راهنمای شخصی‌سازی ربات

این ربات را **مال خودتان** کنید بدون دست‌زدن به منطق بک‌اند. سه محل برای
شخصی‌سازی برندینگ وجود دارد:

### ۱. عنوان اپ (مینی‌اپ)

عنوان فروشگاه **«جاده ابریشم»** است. آن را در
[`src/frontend/index.html`](src/frontend/index.html) تغییر دهید:

```html
<title>جاده ابریشم</title>   <!-- ← به نام برند خود تغییر دهید -->
```

یک خط برنددار هم در [`src/frontend/app.js`](src/frontend/app.js) وجود دارد
(زیرنویس کیف پول):

```js
<div class="sub">موجودی کیف پول شما در جاده ابریشم</div>   // ← «جاده ابریشم» را تغییر دهید
```

### ۲. پیام خوش‌آمد ربات

متن خوش‌آمد `/start` در تابع `sendWelcome()` در
[`src/bot.js`](src/bot.js) قرار دارد:

```js
const text =
  `سلام ${name} 👋\n\n` +
  `به <b>جاده ابریشم</b> خوش آمدید.\n\n` +   // ← نام ربات را اینجا تغییر دهید
  `از طریق دکمه زیر می‌توانید:\n` +
  ...
```

این متن (و عنوان دکمه‌ی `🛍 ورود به فروشگاه` در تابع `mainKeyboard()`) را مطابق
برند، زبان یا لحن خود ویرایش کنید.

### ۳. هویت ربات و دکمه‌ی منوی مینی‌اپ (@BotFather)

- **نام / تصویر / توضیحات ربات** — از طریق @BotFather (`/setname`،
  `/setuserpic`، `/setdescription`، `/setabouttext`).
- **دکمه‌ی منوی مینی‌اپ** — `/mybots` → ربات شما → **Bot Settings** →
  **Menu Button** → ارسال `MINIAPP_URL`. همین کار باعث می‌شود دکمه‌ی آبی
  فروشگاه در چت ظاهر شود.

> 💡 اطلاعات پرداختِ روبه‌مشتری (شماره کارت، صاحب کارت، کانال) **کد نیست** — آن را
> به‌صورت زنده از تب **تنظیمات** پنل ادمین ویرایش کنید.

## 🛠️ توضیح پنل ادمین

پنل ادمین، همان مینی‌اپ است که با `#admin` باز می‌شود. فقط شناسه‌های تلگرامِ موجود
در `settings.admin_ids` می‌توانند به آن دسترسی داشته باشند (در سمت سرور و در هر
درخواست بررسی می‌شود).

| تب | کارکرد |
| --- | ------ |
| **داشبورد** | مجموع فروش، تعداد کاربران، سرویس‌های فعال/منقضی، رسیدهای در انتظار، موجودی VPN. |
| **رسیدها** | بررسی رسیدهای کارت‌به‌کارت در انتظار؛ تأیید برای تکمیل خودکار یا رد. |
| **کاربران** | جستجوی کاربران، مشاهده پروفایل کامل، تغییر کیف پول، مسدود/رفع مسدودی، ارسال پیام مستقیم. |
| **پلن‌ها** | ساخت / ویرایش / حذف (نرم) پلن‌های اشتراک. |
| **VPN** | افزودن اکانت (تکی یا گروهی)، ویرایش، فعال/غیرفعال، حذف موجودی آزاد. |
| **تیکت‌ها** | خواندن و پاسخ به تیکت‌های پشتیبانی؛ بستن موارد حل‌شده. |
| **پیام همگانی** | ارسال پیام به همه‌ی کاربران (به‌جز مسدودها) به‌صورت دسته‌ای و امن. |
| **تنظیمات** | ویرایش شماره کارت، صاحب کارت و آیدی کانال در لحظه. |

رسیدها را **همچنین** می‌توان مستقیماً از چت ربات و با دکمه‌های درون‌خطی ✅/❌ که به
هر عکس رسید فورواردشده پیوست می‌شود، تأیید/رد کرد.

## 👤 توضیح پنل مشتری

فروشگاه مشتری پنج تب دارد (ناوبری پایین):

| تب | کار مشتری |
| --- | -------- |
| 🏠 **خانه** | نمای کلی + لینک‌های سریع به اقدامات اصلی. |
| 🛒 **خرید** | انتخاب پلن، پذیرش شرایط و پرداخت (کیف پول یا کارت). |
| 📦 **سرویس‌ها** | مشاهده اشتراک‌های فعال، روزهای باقی‌مانده و لینک اشتراک؛ تمدید. |
| 💳 **کیف پول** | مشاهده موجودی و تاریخچه؛ شارژ با کارت‌به‌کارت. |
| 🎫 **پشتیبانی** | باز کردن تیکت و گفتگو با ادمین. |

**جریان‌های پرداخت:**
- **کیف پول** ← فوری: موجودی کسر می‌شود، یک اکانت VPN به‌صورت خودکار واگذار می‌شود
  و لینک اشتراک ظرف چند ثانیه توسط ربات تحویل داده می‌شود.
- **کارت‌به‌کارت** ← اپ اطلاعات کارت را نشان می‌دهد؛ مشتری واریز می‌کند و
  **عکس رسید** را برای ربات می‌فرستد. پس از تأیید ادمین، سرویس به‌صورت خودکار
  فعال و تحویل داده می‌شود.

## 🧯 عیب‌یابی

| نشانه | علت محتمل و راه‌حل |
| ----- | ----------------- |
| مینی‌اپ پیام «احراز هویت ناموفق» می‌دهد | اپ را **از داخل تلگرام** باز کنید (دکمه‌ی منو)، نه مرورگر. `initData` فقط داخل تلگرام وجود دارد. |
| ربات به `/start` پاسخ نمی‌دهد | وب‌هوک تنظیم نشده یا آدرس اشتباه است. `setWebhook` را دوباره اجرا و `getWebhookInfo` را بررسی کنید. |
| وب‌هوک کد ۴۰۱ برمی‌گرداند | عدم تطابق `TELEGRAM_WEBHOOK_SECRET`. سکرت را تنظیم و وب‌هوک را با همان `secret_token` دوباره ثبت کنید. |
| دکمه‌ی **پنل ادمین** نیست | شناسه‌ی عددی تلگرام شما در `settings.admin_ids` نیست. آن را به‌روزرسانی کنید (مرحله‌ی ۷ نصب). |
| خطای «ASSETS binding missing» | بلوک `[assets]` در `wrangler.toml` نیست/اشتباه است. آن را از `wrangler.toml.example` کپی کنید. |
| خرید با خطای «ظرفیت تکمیل» شکست می‌خورد | هیچ اکانت VPN `available` در انبار نیست. از تب **VPN** پنل، اکانت اضافه کنید. |
| اشتراک‌ها هرگز منقضی نمی‌شوند | تریگر cron تنظیم نشده. `[triggers].crons` را به `wrangler.toml` اضافه و دوباره دیپلوی کنید. |
| رسید می‌رسد اما سرویس تحویل نمی‌شود | هنگام تأیید، موجودی تمام شده. اکانت اضافه کنید، سپس روی سفارش پرداخت‌شده **تکمیل سفارش** را بزنید. |

برای دیدن لاگ زنده هنگام بازتولید مشکل از `wrangler tail` استفاده کنید.

## ❓ سؤالات متداول

**اجرای آن هزینه دارد؟**
برای حجم کم/متوسط به‌راحتی در پلن رایگان Cloudflare جا می‌شود (Workers، D1 و KV
همگی سقف رایگان سخاوتمندانه‌ای دارند).

**آیا اکانت‌های VPN را خودکار می‌سازد؟**
نه — این پروژه اکانت‌هایی که شما به انبار اضافه می‌کنید را **می‌فروشد و تحویل
می‌دهد**. شما اکانت‌های VPN را تأمین می‌کنید (email / password / لینک اشتراک /
لینک داشبورد) و اپ، فروش، واگذاری و تحویل خودکار را انجام می‌دهد.

**می‌توانم زبان را به انگلیسی تغییر دهم؟**
بله. رشته‌های رابط کاربری به‌صورت درون‌خطی در `src/frontend/app.js`، `src/bot.js`
و فایل‌های سرویس قرار دارند. آن‌ها را در همان‌جا ترجمه کنید؛ `dir="rtl"` در
`index.html` را می‌توانید به `ltr` تغییر دهید.

**آیا فایل `.env` وجود دارد؟**
نه. به راهنمای پیکربندی مراجعه کنید — کانفیگ در سکرت‌ها، `wrangler.toml` و جدول
`settings` قرار دارد.

**می‌توانم چند ادمین داشته باشم؟**
بله. `admin_ids` یک آرایه‌ی JSON است — هر تعداد شناسه‌ی عددی که خواستید اضافه کنید.

**پرداخت‌ها چطور تأیید می‌شوند؟**
پرداخت‌های کارت‌به‌کارت به‌صورت **دستی** توسط ادمین و از روی عکس رسید تأیید می‌شوند.
هیچ درگاه پرداخت خودکاری یکپارچه نشده است.

## 🔒 نکات امنیتی

- **سکرت‌ها هرگز در مخزن نیستند.** `TELEGRAM_TOKEN` و `TELEGRAM_WEBHOOK_SECRET`
  سکرت‌های Cloudflare هستند؛ `wrangler.toml` در گیت نادیده گرفته می‌شود.
- **هر درخواست API احراز هویت می‌شود** با اعتبارسنجی امضای HMAC روی `initData`
  تلگرام (و بررسی تازگی آن) در سمت سرور — درخواست‌ها جعل‌ناپذیرند.
- **وب‌هوک محافظت می‌شود** با اعتبارسنجی هدر `X-Telegram-Bot-Api-Secret-Token`.
- **بررسی ادمین در سمت سرور** و در هر مسیر ادمین انجام می‌شود — هش `#admin` در
  کلاینت فقط یک راهنمای ظاهری است.
- **سکرت‌های VPN فقط برای ادمین.** کد روبه‌مشتری تنها `subscription_url` را افشا
  می‌کند؛ `worker_email`، `dashboard_password` و `dashboard_url` هرگز برای مشتری
  ارسال نمی‌شوند.
- **عملیات مالی race-safe** است (دستورهای `UPDATE` محافظت‌شده برای کسر کیف پول و
  واگذاری اکانت).
- پیش از کامیت، همیشه دیف خود را برای سکرت‌های اتفاقی بررسی کنید. فایل `.gitignore`
  ارائه‌شده شامل `wrangler.toml`، `.dev.vars`، `.wrangler/`، `node_modules/` و
  `*.log` می‌شود.
